# Picture Pieces

Turn any photo into a jigsaw puzzle.

Play: https://mach1rcode.github.io/Picture-Pieces/

- Choose a picture from the device, or use the sample truck.
- Set the number of pieces: 2, 4, 6, 9, 12, 16, 20, 30, 48 or 80.
- Picture styles: Photo, Simple, Cartoon, Dots (pointillism), Mosaic, Sketch and Pop.
- All picture analysis and all filters run in the browser. No picture is uploaded.
- Soft sounds for a pick-up, a correct piece, and a finished puzzle. The sound can be turned off.

## Add to an iPhone Home Screen

1. Open the link above in Safari.
2. Tap Share, then "Add to Home Screen".

The game is one file, `index.html`. It needs no build step.
